민수 브리핑 보드 아키텍처

Telegram 알림 + Tailscale 내부 접속 + Next.js 보드 + JSON/SQLite 하이브리드 저장 구조.
아침 브리핑과 마켓 업데이트가 같은 날짜 페이지로 누적되고, 마켓은 SQLite 시계열까지 적재됨.

사용자 흐름

  • • 텔레그램은 전문 자체보다 링크 허브 역할
  • • 실제 읽기는 Tailscale 내부 웹 페이지에서 진행
  • • URL 형태는 /briefings/YYYY-MM-DD.html 유지
  • • 모바일 브라우저에서도 카드형으로 읽기 쉽게 설계

저장 구조

  • • JSON: 그날 브리핑의 canonical 문서
  • • SQLite briefings: 목록/메타/이전다음 탐색
  • • SQLite market_prices: 차트용 시계열 데이터
  • • 하나의 날짜 페이지에 morning + market이 누적 병합됨

자동화 포인트

  • • 06:00 아침 브리핑 생성
  • • 월/수/금 09:00 마켓 데이터 갱신
  • • Yahoo Finance 기반 RSI / MA 계산 후 적재
  • • systemd user service가 보드를 계속 서빙
